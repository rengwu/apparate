# Apparate 0.1.0

Apparate is a native Swift and AppKit launcher for macOS. Find apps, files, folders and System Settings, or search the web. Browse folders by path, complete results with Tab, choose an app with Open With, and let frequently opened results rise in the list.

## Install

1. Download **Apparate.zip** from this release and unzip it.
2. Move **Apparate** into **Applications** and open it.
3. Follow setup to choose folders and explicitly allow access to Desktop, Documents and Downloads. If Spotlight uses **⌘Space**, setup links to Keyboard Shortcuts so you can free it or choose another Apparate shortcut.

Requires **macOS 27 or later on Apple Silicon (arm64)**. The app is **ad-hoc signed, not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**.

To update, quit Apparate and replace the app. Settings, usage history and the index are kept; an index rule change can require rebuilding the cache.

## Not yet checked on a real Mac

Automated Core and hidden native checks pass. Daily use has not been recorded as formal verification of these paths:

- Input-method composition, non-US keyboard layouts and spoken VoiceOver.
- Lock Screen, Sleep and an actual Restart; automated checks cover arming and cancellation.
- Global shortcut delivery, focus return, Spaces/full-screen behavior, visible panel resizing and spinner animation.
- Actual privacy prompts and grants surviving app replacement; native Login Items registration and approval states.
- Native file/app opening, reveal/copy, Open With, web delivery and failure recovery across the supported paths.
- A launched clean install or upgrade. The extracted archive/signature and headless config/index/history compatibility are checked separately.
- On-screen speed measurements and performance under concurrent indexing. The M6 on-screen stage remains open.

## Known limits

Memory targets have failed in the recorded testing builds: 20,000 items with Settings open reached **49.14 MiB**, above the 40 MiB target, and the 200,000-item run reached a sampled rebuild peak of **103.92 MiB**, above the 100 MiB ceiling. M7 removes test code from the shipped binary but does not requalify runtime memory. See the [20k comparison](https://github.com/rengwu/apparate/blob/v0.1.0/docs/wiki/verification/runs/2026-11-20T111919Z-below-icons.md#memory-comparison-completed), [200k results](https://github.com/rengwu/apparate/blob/v0.1.0/docs/wiki/verification/runs/2026-11-19T115135Z-dot-names.md) and [M6 status](https://github.com/rengwu/apparate/blob/v0.1.0/docs/wiki/verification/runs/2026-11-18T225138Z-m6.md).

Some System Settings deep links reached only the parent pane in the earlier spike, and links sometimes failed to navigate when Settings was already open. Apparate opens the links directly; it does not force-quit or reset System Settings. [Settings link coverage](https://github.com/rengwu/apparate/blob/v0.1.0/docs/wiki/features/settings-items.md).
