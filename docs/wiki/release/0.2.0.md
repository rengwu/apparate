# Apparate 0.2.0

Drag results out of Apparate.

- Drag a file, folder or app from the results and drop it anywhere that takes a drag from Finder: a folder, the Desktop, a Mail message, a browser upload, Terminal or the Dock. A click still opens it.
- As the drag leaves the panel, the panel fades out, so you can drop on whatever is behind it.
- Settings → General → **Dragged files**: **Like Finder** (the default) lets a drop into a folder on the same disk move the file, as Finder does. **Never move** makes it copy instead.
- A completed drop counts toward ranking, like opening the item.

## Install

1. Download **Apparate.zip** from this release and unzip it.
2. Move **Apparate** into **Applications** and open it.
3. Follow setup to choose folders and explicitly allow access to Desktop, Documents and Downloads. If Spotlight uses **⌘Space**, setup links to Keyboard Shortcuts so you can free it or choose another Apparate shortcut.

Requires **macOS 27 or later on Apple Silicon (arm64)**. The app is **ad-hoc signed, not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**.

To update, quit Apparate and replace the app. Settings, usage history and the index are kept.

## Not yet checked and known limits

The drag itself is covered by automated checks, and the fade has been tried by hand. Dropping into particular apps (Mail, browsers, chat apps, Terminal, the Dock) and the Never move choice with each of them haven't been checked by hand yet. Other limits are unchanged; see the [0.1.0 notes](https://github.com/rengwu/apparate/releases/tag/v0.1.0).
