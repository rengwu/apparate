# Features

M1 supplies the headless foundation. M2 adds applications, System Settings items, typed actions, a first panel and explicit folder-access checks. M3 adds persistent file discovery, live updates and apps found inside indexed folders. M4 adds the final launcher layout, scrolling, numbered actions and accessible rows. Settings and final performance qualification follow in later [milestones](../plan.md).

- [Search](search.md) — FEAT-search: scopes, names, paths, ranking, usage and complete result delivery.
- [Config](config.md) — FEAT-config: versioned JSON, validation, last-valid state and external edits.

- [File index](file-index.md) — FEAT-file-index: chosen folders, ignore rules, compact snapshots, persistence and live updates.
- [Applications](apps.md) — FEAT-apps: bundle discovery, canonical paths and live updates.
- [System Settings items](settings-items.md) — FEAT-settings-items: localized panes, entries and disposable cache.
- [Opening and commands](actions.md) — FEAT-actions: typed opens, reveal, copy, web and system commands.
- [Launcher panel](panel.md) — FEAT-panel: compact inline layout, scrolling, ID-based actions, accessibility and shortcut registration.
- [Folder access](access.md) — FEAT-access: explicit sequential checks and saved observations.

See [verification setup](../verification/setup.md) for repeatable commands and isolation.
