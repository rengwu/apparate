# Skip hidden files

[UI section 12](../../build/ui-follow-up.md#12-skip-hidden-files) implements DEC-059 with the corrected **default on**. The Folders tab adds **Skip hidden files** directly below the `.gitignore` switch in the same card, with no description. Config, indexing and Settings behavior are documented in [config](../../features/config.md#skip-hidden-files), [file index](../../features/file-index.md#skip-hidden-files) and [Settings](../../features/settings.md). The section-11 memory comparison was pending at this handoff and was later completed in its own report; this run does not substitute for that measurement.

## Implementation

Optional v1 `skipHiddenFiles` defaults to true, including old configs that omit it. Invalid types reject the document. The native switch saves against its last rendered value, preserves unrelated external edits, rejects same-field conflicts, refreshes after external changes and disables with broken config.

When on, the crawler filters dot-prefixed names before metadata reads. Their descendants are not visited. Finder-hidden non-dot names remain eligible. Explicit roots retain their own membership, including nested dot roots; ordinary children are indexed and watched, while dot children are omitted unless configured independently. `.gitignore` is still read and watched for rules even though its own entry is skipped. Direct paths keep the existing behavior: a dot-prefixed final filter can find dot names, while a bare trailing slash lists ordinary names.

File-rule signature 6 includes the policy. A legacy or different-policy cache rebuilds once. The snapshot persists its policy, and incremental updates inherit it. A toggle immediately filters the old snapshot and discovered-app catalog before rebuilding, with revision guards against obsolete work. Failed reads cannot retain forbidden dot memberships. The builder counts underlying graph memberships before removing entries from a pending filtered view, preventing double subtraction from the displayed count.

With the switch off, section-6 terminal dot entries and query gates remain. Low-level crawler callers without a config retain their legacy default; production always passes the config value explicitly. The comparison driver now writes off explicitly and records that choice so its established dot-inclusive corpus stays comparable.
