Inspection found that `FileIndexBuilder.set` copied a chunk even when the node was unchanged. File nodes and application metadata now compare their complete values before creating an edit. An unchanged rebuild preserves prepared chunks; changes to metadata, membership, children or application presentation still invalidate them. This preserves immutable snapshots. File scan counts now include no-change scans, so idle classification cannot hide them merely because nothing was published.
