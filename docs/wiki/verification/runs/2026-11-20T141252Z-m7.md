## Compatibility scope

`Tests/upgrade-check.py` extracts baseline Core from the exact base commit, builds the new nonshipping harness against it in an owned temporary package, seeds a disposable config/index/history, and reads it with the candidate production-mode Core harness. It uses explicit temporary data/root paths and an injected quiet watcher. The unchanged depth-10 root loads without a full scan; this does not promise that intentionally shallow startup refreshes or changed indexing rules never crawl.

The [seed](../../evidence/2026-11-20T141252Z-m7/upgrade/seed.json) and [candidate](../../evidence/2026-11-20T141252Z-m7/upgrade/check.json) agree on all eight comparison fields, including four searchable entries and remembered application/usage state. Config bytes are unchanged. Baseline/candidate harness hashes and cleanup are in the comparison receipt. No config schema or Core source changed in M7. This check does not exercise actual app replacement, TCC grants, Launch Services, quarantine or native Login Items.
