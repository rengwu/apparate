# Right Arrow completes folders

Section 9 / DEC-058 implements the four confirmed details in [guide row 31](../../build/ui-follow-up.md). Plain Right at the end of the search field completes the current accepted folder through the same native replacement helper as Tab. The [panel record](../../features/panel.md) and [repeatable setup](../setup.md#right-arrow-folder-completion) describe the behavior and checks.

## Behavior

Completion requires a folder, one empty selection at the UTF-16 end, editor text equal to the model query, and no marked text. Existing completion guards exclude pending, hidden and Open With states. Home-abbreviated paths, trailing slash, dropped scope prefix and native undo/redo match Tab. Right is consumed only when replacement occurs; Tab keeps its existing always-consumed behavior. An identical completion does not add an undo action.

Right is handled by `moveRight:` after the input-method guard. The owned panel records key context during normal dispatch without intercepting Right ahead of the editor. Shift, Option, Command and Control modifiers exclude completion; incidental function/numeric-pad flags do not. Eventless native commands remain supported. All other cases return to AppKit. Footer text is unchanged. No new repeat policy, search behavior, config or Core code was added.
