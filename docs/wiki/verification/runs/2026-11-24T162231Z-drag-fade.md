# Drag-exit fade

The panel closes its session when a drag leaves. AppKit animates the window’s opacity over 0.15 seconds with the default timing and orders the window out on completion. This run exercises the dismissal, completion and interruption paths in a non-presenting window. Visible timing, Finder and Desktop delivery, and a physical hotkey press during the fade await supervision. [Section 7](../../build/drag-out.md#7-fade-out-when-the-drag-leaves), [FEAT-panel](../../features/panel.md#drag-results-out), [previous run](2026-11-24T093455Z-drag-policy.md).

## Build and isolation

The base was `e4bdd372a3cf05535b8ba70dd0a3c901d2d1e1cc` with the uncommitted section 7 changes, on macOS 27.0 (26A5368g), arm64, Apple Swift 6.4.2. The fixture profiles use temporary app homes, synthetic rows, a private pasteboard and fake actions. The panel harness sends events to its own window and calls the drag source with synthetic points. It counts calls to the native window’s `orderOut` method and exercises the same toggle the global hotkey calls. [Source manifest](../../evidence/2026-11-24T162231Z-drag-fade/source-manifest.json).
