# Direct paths and shallow folder discovery

Section 5 of the [UI follow-up](../../build/ui-follow-up.md), DEC-054, adds directory navigation and shallow home/root discovery. Claude accepted the six implementation details before building, then accepted the Allow Access button integration. This run covers [search](../../features/search.md), [file indexing](../../features/file-index.md), [panel](../../features/panel.md), [config](../../features/config.md), [access](../../features/access.md), [Settings](../../features/settings.md) and [first run](../../features/first-run.md). Hidden checks pass; actual keyboard delivery, native prompts and WindowServer presentation remain Untested.

## Behavior

After prefix parsing, leading `/`, `~/` and exact `~` list one directory on a serial worker. The final name uses the usual matcher, with at most 50 rows; an empty filter lists names alphabetically. Dot names require a dot at the start of that filter, and `node_modules` is visible. Files and packages are leaves; directory links may be followed. No index write or directory watch is added. New generations cancel stale work/publication; an already running filesystem call cannot be interrupted. A single-directory cache survives name-filter changes and is cleared on directory changes, leaving path mode, hide/show and access changes. Catalog readiness does not block this mode.

Tab completes a current selected folder through the native field editor, with a trailing slash and home abbreviated as `~`, dropping any scope prefix. Pending or marked text and file rows do not complete. Return, ⌘Return and ⌘C keep the existing filesystem action routes. There is no web fallback. Missing, unreadable, non-folder and access-needed messages are distinct. A slash elsewhere keeps DEC-031 indexed matching and its existing fallback rule.

Protected paths are checked lexically and through canonical aliases before metadata/listing. Protected parents are canonicalized without probing the protected directory; this also handles `/var` versus `/private/var` fixture homes. Missing Allowed observations do not trigger a prompt. The explicit Settings → Folders → Allow Access… button remains available even with an empty index list, so the message leads to an available control. Other typed folders may cause macOS prompts, as accepted in DEC-054; no such prompt was exercised here.

New/default folder lists append `~` and `/`, depth 1, after Projects/Desktop/Documents/Downloads. Existing explicit lists, including empty ones, stay unchanged. Overlap supplies each entry once. Depth-1 roots use directory vnodes, with startup/rearm rechecking and nonrecursive missing-root recovery. Nested configured recursive roots retain their own FSEvents coverage; discovered mount points do not widen a shallow boundary. Finder-hidden entries are included; dot names and `node_modules` remain excluded from indexing. File-rule signature 4 rebuilds older exclusions. Equal tier/kind/score-plus-usage file/folder matches prefer fewer path components before folded name, consistently in flat, compact and merged search, without full-path construction in the compact comparison loop.

## Native input investigation

The other was a test incorrectly expecting no web fallback for an internal relative slash; it now preserves DEC-031. [Initial log](../../evidence/2026-11-19T095817Z-path-folders/attempt-core-debug-first.log).

The panel now observes history-completion notifications, filters them to the current editor’s UndoManager, and reconciles the query once on the main actor after the transaction. The test sends the native editor’s `undo:` command and checks its actual restored text, search state and subsequent typing. Direct hidden inputs can share an event undo group; the test does not claim the grouping of separate physical keys. Manual undo-group experiments were discarded.

The native Return check also exposed an existing unsafe `isARepeat` read on a non-key current event, which could stop the hidden task. Return now checks the event type first. The final signed run records current event type **13**, successfully routes Return/reveal/copy, then continues typing and rendering. Failed attempt receipts and progress records remain in this run; redundant prerequisite images from failed attempts are archived in the owned temporary directory recorded by each `render-archive.json`.
