# Drag results out of the launcher

[FEAT-panel](../../features/panel.md) and the [drag-out brief](../../build/drag-out.md) cover one file, folder or app dragged from the launcher. The hidden panel exercises the production mouse-down and mouse-up methods and the methods AppKit uses to prepare a drag and report its progress. External destinations and the visible drag session require the [supervised checks](../../features/panel.md#supervised-recipes-untested).

## Build and isolation

Base revision `15f1d3ae755b7e152dbf6031d74892588c185f52` (v0.1.1), with uncommitted changes. macOS 27.0 (26A5368g), arm64, Apple Swift 6.4.2. The [source manifest](../../evidence/2026-11-24T074838Z-drag-out/source-manifest.json) identifies the inputs. Testing uses Command Line Tools, a separate SwiftPM build directory, a non-presenting panel and synthetic catalog entries. Each smoke driver creates and cleans up its own data directory. The pasteboard check writes and reads a new private pasteboard. No general clipboard or user files are involved.

## Reproduction and evidence

Run the [isolated build and smoke recipes](../setup.md#m7-release-build-and-hidden-checks) with `DEVELOPER_DIR=/Library/Developer/CommandLineTools`, testing scratch `/private/tmp/apparate-20261124-drag-out` and review bundle `build/review/2026-11-24-drag-out/Apparate.app`. The final debug build and signed release testing build ran the functional panel profile. The signed release testing build also ran the Settings profile. The production build used `./build.sh`, the production-mode release Core suite and the archive checker.

Production passes the original mouse-down event to AppKit for the drag image offset and checks the drag cursor against the panel frame in screen coordinates. [AppKit drag initiation](https://developer.apple.com/documentation/appkit/nsview/begindraggingsession%28with%3Aevent%3Asource%3A%29), [drag cursor location](https://developer.apple.com/documentation/appkit/nsdraggingsession/dragginglocation).

The final debug run also records the pending survivor, absent replacement, composition guard and cleared-row checks. [Debug panel receipt](../../evidence/2026-11-24T074838Z-drag-out/debug-final-panel.json).

The system drag-initiation distance returned by HIToolbox on this Mac was 4 points on each axis. The initial build used a document symbol while the row icon was loading. The post-review build uses the Workspace icon for that path. The test supplies synthetic mouse events directly to the result view and stops at the prepared dragging item. The drag-position and completion calls use injected screen points. No Finder operation, file mutation or physical input was observed.

The first debug build failed in the verification harness because two receipt labels used the numeric `ItemKind.rawValue` where Swift required a string. Using the case name fixed the build. The linker issued missing search-directory warnings for the Command Line Tools installation. The build logs are retained under `build/checks/2026-11-24-drag-out/`.

The report metadata checker accepted all 25 runs. The wiki rebuild and freshness check passed for 68 pages and their internal links. All 91 source-manifest entries matched the working tree, and `git diff --check` passed.

## Post-review fix

The panel now dismisses on key loss even when a drag is inside its frame. Drag preparation reuses the loaded row icon or asks Workspace for the pressed path’s icon if the row is still loading. The [updated source manifest](../../evidence/2026-11-24T074838Z-drag-out/review1/source-manifest.json) differs from the initial run in `PanelController.swift` and `PanelRows.swift` only.

The Core suite passed 134/134. Both hidden panel profiles passed with zero native actions and zero stderr bytes. The signed arm64 production bundle and its extracted archive matched. The wiki rebuild and freshness check passed for 68 pages. [Core](../../evidence/2026-11-24T074838Z-drag-out/review1/core.log), [debug panel](../../evidence/2026-11-24T074838Z-drag-out/review1/debug-panel.json), [signed release panel](../../evidence/2026-11-24T074838Z-drag-out/review1/panel.json), [review bundle identity](../../evidence/2026-11-24T074838Z-drag-out/review1/review-identity.json), [production artifact](../../evidence/2026-11-24T074838Z-drag-out/review1/artifact.json).

The fixtures supplied loaded icons and used a non-presenting panel. Live key loss during a drag, cold-icon appearance and the external drops remain **Untested**. The earlier Settings receipt applies to the initial build.
