# Open With

Section 8 / DEC-057 implements all five confirmed proposals in the [guide](../../build/ui-follow-up.md). A file/folder's configurable Open With key opens an app-selection mode; successful opens remember the chosen app per content type. Affected records: [panel](../../features/panel.md#open-with), [actions](../../features/actions.md#open-with), [Settings](../../features/settings.md#open-with-shortcut), [config](../../features/config.md#open-with-key), [search](../../features/search.md) and [file-index persistence](../../features/file-index.md). Repeatable commands and isolation are in [setup](../setup.md#open-with-checks).

## Behavior and boundaries

Default ⇧Return is a panel-local key. General has an Open With keycap recorder; it allows modified nonprinting keys, rejects Shift-only typing keys, and protects the launcher shortcut, panel navigation/actions and native editing shortcuts. External config edits receive the same validation; conflicting stale saves cannot overwrite a newer key. No extra Carbon registration is installed.

Only current accepted file/folder rows enter. The field clears and shows `Open notes.md with…`. App groups are remembered, default, other claimed apps, then other catalog apps while typing. Empty-query claimed apps are A–Z; typed text uses ordinary name matching within each group. App URLs deduplicate. A valid remembered unclaimed app remains first; missing remembered apps are skipped. Last used wins the label when the app is also default. Filters are literal app names, with no launcher prefixes, paths or web fallback. The existing 50-result cap and scrolling apply.

Discovery, app metadata, type lookup, existence checks and matching run away from the main thread. Lexical and canonical protected-folder checks precede lookup; no new watcher, polling, permission probe or file-content read is added. Generation cancellation rejects late lookup/filter results. Esc returns directly to the saved query/selection/viewport, including from a nonempty filter. Changed sources/config/access require revalidation; a surviving selection is restored by ID. A later edit/navigation cancels deferred position restoration. Hide/new showing drops the mode.

Return/click/⌘1–9 dispatch the original item and chosen application URL, then hide. Tab/backtab, ⌘Return and ⌘C do nothing in the mode; composition keeps its normal ownership and the configured trigger cannot escape it. Quit and Settings remain available. Empty discovery shows No applications. User-action errors take the existing alert path. A missing chosen app never evicts the original item as missing.

After Workspace accepts an open, one SQLite transaction records item usage and the type choice. The bounded table holds at most 128 types, evicting the oldest successful choice. Folders use `public.folder`; unresolved types open and record usage without a type preference. Failed opens and browsing record neither. Schema 3 migrates existing usage/file data additively. Earlier binaries limited to schema 2 cannot open a schema-3 database; no downgrade migration is provided. No real user database was accessed or migrated in these checks.
